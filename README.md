MCPfolio is an MCP server directory that helps you find the right tools for your AI assistant. Discover Model Context Protocol servers for development, productivity, databases, web search, browser automation, and more.

Explore server capabilities, supported AI clients, connection options, and setup requirements in one place. Find integrations for tools such as GitHub, Notion, Supabase, Firecrawl, and Playwright, with setup guidance for clients including Cursor, VS Code, Claude, and Codex.

Browse curated collections organized around tasks such as researching the web, working with codebases, connecting application data, and coordinating team projects. Explore practical workflows that show how multiple MCP tools can work together.

Whether you’re a developer connecting tools to an AI coding assistant or a team exploring MCP integrations, MCPfolio helps you discover relevant servers and understand how to get started.
